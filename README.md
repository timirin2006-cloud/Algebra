# Алгебра 7 класс: преобразование выражений

Интерактивный сайт для повторения темы. Открывается в браузере, устанавливать ничего не нужно.

## Что внутри

- **Теория:** приведение подобных, раскрытие скобок, вынесение общего множителя, формулы сокращённого умножения.
- **6 задач** трёх уровней (по 2 на каждый): лёгкий, средний, сложный.
- У каждой задачи 4 варианта ответа, подсказка и полный разбор с проверкой.
- Полоска прогресса и счётчик верных ответов, кнопка «Пройти заново».
- Светлая и тёмная тема, удобно с телефона.

## Как запустить

**Локально:** открой `index.html` двойным щелчком.

**GitHub Pages:** загрузи файлы в репозиторий, затем **Settings → Pages → Deploy from a branch**, ветка `main`, папка `/ (root)`. Сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.

## Структура

```
.
```

## Как добавить задачу

В `index.html` найди массив `T` и добавь объект:

```js
{ g: 1,                       // уровень: 0 лёгкий, 1 средний, 2 сложный
  q: "Текст задачи",
  o: ["вариант 1", "вариант 2", "вариант 3", "вариант 4"],
  a: 0,                       // номер верного варианта (с 0)
  h: "Подсказка",
  s: "Решение по шагам" }
```

Задачи в массиве держи по порядку уровней: сначала лёгкие, потом средние, потом сложные.
